## 🚀 Key Featured Projects

### ✈️ Flight Booking Platform (Flagship)
*An interactive flight lookup and reservation application.*
- **Tech Stack:** React, Next.js, TypeScript, PostgreSQL, Express, Tailwind CSS
- **Features:** 
  - Responsive multi-parameter search engine filtering by stops, price, and schedule.
  - Interactive seat selector grid map for booking management.
  - PostgreSQL schema optimized for fast query lookups across multiple flight paths.
- **Link:** [Live Demo](https://flight-bookings.vercel.app/) | [Source Code](https://github.com/lokeshparasuraman/flight-bookings)

### 🔒 Chain of Custody Secure Ledger
*Cryptographic evidence logging application designed to maintain forensic records.*
- **Tech Stack:** React, Node.js, MongoDB, Express, Cryptographic SHA-256 Hashing
- **Features:**
  - Secure sequence hashing logic (SHA-256) validating audit trails on database operations.
  - Integrity alerts flagging hash mismatch inconsistencies immediately.
  - Role-based routing and secure JWT authentication protocols protecting legal logs.
- **Link:** [Source Code](https://github.com/lokeshparasuraman/CHAIN-OF-CUSTODY)

### 🤖 Todo Summarizer (AI Agent)
*Automated productivity workflow digesting logs into structured summaries.*
- **Tech Stack:** React, Node.js, MongoDB, OpenAI GPT models, Slack Webhook API
- **Features:**
  - OpenAI GPT model prompt pipeline summarizing dev logs into formatted reports.
  - Scheduled Slack bot webhook routing daily summaries directly to targeted workspaces.
  - Optimized MongoDB queries caching historical summaries.
- **Link:** [Source Code](https://github.com/lokeshparasuraman/todo-summarize)

## 💻 Retro CLI Terminal Emulator
One of the key interactive elements of this portfolio is the **fully functioning retro Terminal component**:
- Supports custom shell commands: `help`, `about`, `skills`, `projects`, `experience`, `contact`, `clear`.
- Includes easter eggs like `sudo hire lokesh` which launches a mailto flow!
- Listens to global keystroke events for terminal focus when visible in the viewport.

## ⚙️ Getting Started & Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/lokeshparasuraman/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to see the results.
