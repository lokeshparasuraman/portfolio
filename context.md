# Portfolio Project Context

## Project Overview
A modern, minimalist portfolio for a fresher developer, built with Next.js, TypeScript, and Tailwind CSS. The design focuses on clarity, professional aesthetics, and ease of maintenance.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **Icons:** Lucide React, React Icons
- **Deployment:** Vercel

## Architecture
The project follows a modular structure to allow easy updates:
- `src/data/`: Centralized location for all content (projects, skills, social links).
- `src/components/ui/`: Reusable primitive components.
- `src/components/layout/`: Layout-specific components like Navbar and Footer.
- `src/components/sections/`: High-level page sections.

## Design Principles
1. **Minimalism:** Use whitespace effectively and limit the color palette to a primary dark theme with subtle accents.
2. **Responsiveness:** Mobile-first approach for all components.
3. **Performance:** Optimized images and minimal client-side weight.
4. **Maintainability:** Content is separated from logic via the `src/data/` directory.

## Current State
- Redesigning from a more complex, multi-colored layout to a "neat and clean" aesthetic inspired by professional senior portfolios but tailored for a fresher.
